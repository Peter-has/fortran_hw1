環境

GNU Fortran (Rev4, Built by MSYS2 project) 16.2.0；以 winget install --id MSYS2.MSYS2 -e 安裝 MSYS2，再用 pacman -S mingw-w64-ucrt-x86_64-gcc-fortran 安裝 gfortran。

程式碼（sum.f90 原版）

program sum_to_n
    implicit none
    integer :: n, i, total

    print *, "Enter a positive integer N:"
    read *, n

    if (n < 1) then
        print *, "Error: N must be a positive integer"
        stop
    end if

    total = 0
    do i = 1, n
        total = total + i
    end do

    print *, "Sum of 1 + 2 + ... + N =", total
end program sum_to_n

編譯與執行

gfortran sum.f90 -o sum.exe
.\sum.exe
Enter a positive integer N:
10
 Sum of 1 + 2 + ... + N =          55

N=10 輸出 55，與公式 10×11÷2 = 55 相符。

遇到的問題與解決

  • 編譯結束代碼為 1 且無錯誤訊息。用 -v 追查，單獨執行 f951.exe 得到 -1073741511（0xC0000139，找不到 DLL 進入點）。
  • 原因：PATH 中 Anaconda 的 libgmp、libgcc_s、libstdc++、libwinpthread 與 MSYS2 同名且排在前面。
  • 解決：將 C:\msys64\ucrt64\bin 移到使用者 PATH 最前面，新開 PowerShell 後編譯成功（結束代碼 0）。
  • 中文提示在終端機顯示亂碼，改用英文提示。

逐行註解版（節錄）

! Program: sum_to_n
! Purpose: Read a positive integer N and compute 1 + 2 + ... + N
program sum_to_n
    ! Require every variable to be declared explicitly
    implicit none
    ! n: upper limit entered by the user; i: loop counter; total: running sum
    integer :: n, i, total
    ...
    ! Initialize the running sum to zero before accumulating
    total = 0
    ! Loop i from 1 to N, one step at a time
    do i = 1, n
        ! Add the current value of i to the running sum
        total = total + i
    end do
    ...
